The Pharmacy Management System is a desktop application built with ASP.NET (WinForms, C#) and MSSQL. It streamlines pharmacy operations by managing medications, prescriptions, inventory, sales, and billing efficiently.

Key Features
User Roles: Admin & Salesperson modules.
Inventory & Billing: Tracks stock, purchases, and sales transactions.
Excel Import/Export: Easily manage medicine data with an Excel converter.
Web Search: Look up unavailable medicines online directly from the application.
Enhanced UI: Uses Guna Framework for a modern and user-friendly experience.
